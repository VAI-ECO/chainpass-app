# CLIENT DASHBOARD — assets

**Nothing is delivered.** These are operator list surfaces: tables, rows of reads, and form controls.

**No face, no document, no baseline artwork.** §14.7 never-list 2 — none is readable by a platform, so there is no slot for one on any client surface.

**No price.** The credential is the provider's product and it states its own price. Purchase leaves this surface entirely.

**No percentage badge and no rate figure.** A percentage is never readable by a platform, so the commission ledger shows amounts accrued, scheduled and paid, and no rate.

**No chart images.** Series are tables with an em-dash where a read goes. A chart with invented values is a figure with decoration around it.

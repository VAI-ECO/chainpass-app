# 0 — ONE SPINE, THREE FLOWS

**Every level walks the same spine. The flows differ in exactly three places.**

| | VAIRIFY FLOW | VAI PRO | VAI GO + VAI ACCESS |
|---|---|---|---|
| **Outside the walls** | ⚠️ Real information to Offenders.io. **Yes or no comes back. Nothing else.** | ⚠️ A custom pipeline per platform. **The pipeline is free; the service it connects to may carry a fee.** | **None.** |
| **Documents signed** | LE disclosure · signature agreement · T&C | T&C · custom platform requirements **not requiring real-life ID** | T&C |
| **Retrieval page brand** | VAIRIFY-branded | platform-branded | platform-branded |

⬜ **§5 item 6 — "PASS" is a level name the register does not have.** Flagged, not renamed.

# 1 — THE SPINE — THIRTEEN STEPS

| # | Step |
|---|---|
| **1** | **The client lands in ChainPass** — sent by a platform, or choosing a platform on the ChainPass site. ⚠️⚠️ **NO PLATFORM DECLARATION, NO ENROLMENT.** |
| **1a** | ⚠️ *Optional information page. It sells nothing and gates nothing.* |
| **2** | ⚠️⚠️ **PAY. RULED 25 AUGUST — PAYMENT HAPPENS BEFORE ANY OF THIS.** The deferral offer lives here. **Nothing downstream begins until it clears.** |
| **3** | **ChainPass creates a 30-character alphanumeric session key.** |
| **4** | **ChainPass hands the client to the KYC company.** |
| **5** | ⚠️⚠️ **CHAINPASS OWNS THE CAMERA AND CAPTURES THE IMAGE: THE BASELINE.** |
| **5a** | **The level's outside-the-walls step runs** — §0 row 1. |
| **6** | **The KYC company's verification completes.** |
| **7** | **The biometric image, the level's result, and the session key return to ChainPass.** |
| **8** | ⚠️ **THE V.A.I. IS MINTED** — 7 characters, alphanumeric — **AND ATTACHED TO THE IMAGE.** |
| **9** | **Confirmation and the V.A.I. are shown.** Contact collected: for ChainPass, email or phone; for platforms, username, email and phone as that platform requires. **An OTP is sent.** |
| **10** | **OTP confirmed — control proven — the level's documents are signed (§0 row 2), THEN A FACE MATCH CONFIRMS IDENTITY against the step-5 baseline.** |
| **11** | ⚠️⚠️ **THE RETRIEVAL PAGE — A CHAINPASS PAGE, BRANDED PER §0 ROW 3.** Three questions · the one-time passwords · the message urging an email or phone partner. |
| **11a** | ⚠️⚠️ **THE FINAL PAGE — THE USER'S V.A.I., SHOWN ONE LAST TIME, AND ONE QUESTION: DOES THE USER WANT IT REMEMBERED ON THIS DEVICE?** A CHAINPASS PAGE AND A CHAINPASS FUNCTION. |
| **12** | ⚠️ **THE HANDOFF.** The platform receives the V.A.I., the session key, its required documents and the T&C affirmation. |
| **13** | ⚠️⚠️ **CHAINPASS DELETES THE SESSION KEY. AFTER THE HANDOFF, NEVER BEFORE.** |

## 1.1 — ⚠️⚠️ STEP 11a — REMEMBERING THE V.A.I.

⚠️⚠️ **THIS IS A CHAINPASS FUNCTION. THE PLATFORM NEVER ASKS IT, NEVER STORES THE ANSWER,
AND NEVER SEES THE DEVICE.**

| # | |
|---|---|
| 1 | ⚠️ **The V.A.I. is displayed one last time before the user leaves ChainPass.** The user will need it at every entrance for the rest of the membership. |
| 2 | ⚠️⚠️ **THE QUESTION IS ASKED, NEVER ASSUMED. DEFAULT IS NOT REMEMBERED.** |
| 3 | ⚠️⚠️ **BOTH ANSWERS ARE FREE OF CONSEQUENCE. DECLINING COSTS NOTHING AND THE COPY NEVER PRESSES.** The user may be on a borrowed phone, a shared phone, or a phone the user does not want it on. |
| 4 | ⚠️ **Remembered means remembered on THIS DEVICE.** ⚠️⚠️ **NEVER A CROSS-DEVICE RECORD. NEVER A SETTING ON THE CREDENTIAL. NEVER A FIELD A PLATFORM CAN READ.** |
| 5 | ⚠️ **The user can undo it later from any ChainPass entrance,** and undoing it needs no sign-in — the same shape as the locked screen. |
| 6 | ⚠️⚠️ **REMEMBERING THE NUMBER IS NOT SIGNING THE USER IN. THE FACE STILL RUNS EVERY TIME.** A remembered V.A.I. fills a field and does nothing else. |
| 7 | ⚠️ **If the user declines and later loses the number, the route back is the recovery just set at step 11.** That is why 11 precedes 11a. |

# 2 — RULES BINDING ALL THREE

| # | |
|---|---|
| 1 | ⚠️⚠️ **EVERY USER CARRIES A REQUESTING-PLATFORM DECLARATION.** |

| 5 | ⚠️⚠️ **PAYMENT IS FIRST. THE CLOCK STILL STARTS AT VERIFICATION, NOT AT PAYMENT** — `CANON-CP-01` §4A.2. |

# 3 — ⚠️ WHAT CHAINPASS DOES. THE CHAINPASS CANON'S LIST.

**ChainPass owns steps 1 to 13. All of them.**

| # | |
|---|---|
| 1 | **Take the platform declaration.** Reject anyone arriving without one. |
| 2 | ⚠️⚠️ **TAKE PAYMENT FIRST.** Offer the deferral. Start nothing until it clears. |
| 3 | **Mint and hold the session key.** 30 characters. Never in a URL, never in the browser. |
| 4 | **Drive the KYC company in an embedded frame.** Never a redirect. |
| 5 | ⚠️⚠️ **OWN THE CAMERA. CAPTURE THE BASELINE. HOLD IT UNCOMMITTED.** |
| 6 | **Send real details out to the checker, take back yes or no.** Store no detail. |
| 7 | **Mint the V.A.I.** and bind it to the image. |
| 8 | **Collect the contact the platform requires. Send and verify the OTP.** |
| 9 | **Serve the documents, take the signatures, hold them versioned and immutable.** |
| 10 | **Run the confirming face match** against the step-5 baseline. Pass or fail. No score. |
| 11 | ⚠️⚠️ **SERVE THE RETRIEVAL PAGE, BRANDED FOR THE PLATFORM. STORE THE QUESTIONS AND THE ONE-TIME PASSWORDS.** |
| 11a | ⚠️⚠️ **SHOW THE V.A.I. ONE LAST TIME AND ASK WHETHER TO REMEMBER IT ON THIS DEVICE.** Hold the answer device-side. Never on the credential. |
| 12 | **Push the handoff server to server.** V.A.I. · session key · documents · T&C affirmation. |
| 13 | ⚠️ **DELETE THE SESSION KEY.** |
| 14 | **Answer the gate afterwards, forever.** One word. Never why. |

## 4.1 — ⚠️⚠️ WHAT VAIRIFY NEVER DOES

| # | |
|---|---|
| 1 | ⚠️⚠️ **NEVER TAKES PAYMENT FOR THE CREDENTIAL.** |
| 2 | ⚠️⚠️ **NEVER SETS OR STORES THE SECURITY QUESTIONS OR THE ONE-TIME PASSWORDS.** |
| 3 | ⚠️⚠️ **NEVER SENDS THE ENROLMENT OTP.** |
| 4 | ⚠️⚠️ **NEVER CAPTURES, STORES OR MATCHES A FACE. NO PHOTOGRAPH, NO VECTOR, NO SCORE.** |
| 5 | ⚠️⚠️ **NEVER HOLDS A LEGAL NAME OR A DOCUMENT.** |
| 6 | ⚠️ **NEVER UNLOCKS AN ACCOUNT.** The only route out is re-verification at ChainPass. |
| 7 | ⚠️⚠️ **NEVER ASKS WHETHER TO REMEMBER THE V.A.I., NEVER STORES THAT ANSWER, AND NEVER READS IT.** Step 11a is ChainPass's. **A REMEMBERED NUMBER FILLS A FIELD; IT NEVER SIGNS ANYONE IN.** |

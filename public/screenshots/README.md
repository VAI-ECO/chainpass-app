# PWA Screenshots

This directory should contain screenshots of the app for PWA store listings.

## Required Screenshot

- `mobile-1.png` - 540x720 pixels (portrait mobile screenshot)

## Additional Recommended Screenshots

- Desktop screenshots (if applicable)
- Landscape mobile screenshots
- Tablet screenshots

## Generation Instructions

1. Take a screenshot of the main page or key feature
2. Resize to 540x720 pixels (portrait orientation)
3. Save as `mobile-1.png` in this directory

The screenshot will be used in PWA install prompts and app store listings.
